# 领域约定

## 核心对象

原始事实（仅追加、逐字保存）：

- 药品追溯事件（一药一码：生产赋码、出库、入库、发药、流通扫码）
- 医保结算记录（参保人就医结算，含盒级用药明细）
- 流通凭证（发票、资金台账、冷链运单等票账货款材料）
- 扣押批次（仓库扣押登记，含包装受损、码面涂改的原始描述）
- 网络销售线索（平台商品页、取证快照）
- 办案协作（跨省协查函件与来文）

派生与办案对象：

- 数据切点（作业时刻的只读版本边界）
- 核查线索及其追加版本（规则、参数、证据快照、解释）
- 人工研判决定（认领、备注、排除、风险确认、移送，只追加）
- 案件与案件成员（分级查看）
- 封存包（清单与封存哈希）
- 跨省交接单与签收回执

## 已知规则（铁律）

- 历史事件不得被更正覆盖，更正只能追加版本并记录原因
- 重复上传不得产生新版本，但送达事实要留痕
- 迟到数据按业务时间识别，照常入库、触发复评，不插队改写历史
- 风险提示与违法认定必须分离：系统只报风险，定性权属法定程序
- 机器复评不得翻案人工已作出的排除/确认/移送决定
- 封存与交接以哈希自证；接收方核验不一致必须如实记录、不得签收采信
- 公众查询不得暴露案件、侦查和参保人敏感信息，只给单盒合法流转摘要
